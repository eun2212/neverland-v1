# 그림 프로토타입 01

**네버랜드: 키퍼의 놀이공원**의 일러스트 기반 비주얼 노벨 프로토타입입니다.

플레이: https://neverland-keeper-park.cometibex2.chatgpt.site/

## 실행

저장소 전체를 내려받아 `index.html`을 브라우저에서 여세요. 그림은 `assets/`에 포함되어 있으므로 함께 보관해야 합니다. 별도 설치·AI API·서버 없이 실행됩니다. 엔딩 기록은 플레이한 브라우저에 저장됩니다.

## 포함된 기능

- 프로필 및 남/여 선택, 놀이기구 성향에 따른 대화
- 캡틴 훅 프롤로그와 고정 사고, 네버랜드의 실체 컷씬
- 다섯 놀이기구별 조작 미니게임, 키퍼 도움, 일러스트 지도
- 대화와 행동 누적에 따른 다섯 엔딩 및 성별별 엔딩 이미지
- 퍼레이드와 주사위 이벤트, 선택한 P1/D3 이벤트 컷씬

## 권리 안내

제작자의 작품입니다. 별도의 오픈소스 이용 허락을 부여하지 않습니다. 무단 수정·복제·재배포를 금지하며, 플레이 링크 공유는 가능합니다. 이 저장소는 비공개 보관을 기본으로 합니다.

이 버전은 공개 중인 일러스트 프로토타입을 보관한 것이며, 별도의 3D·후속 버전과 구분됩니다.
